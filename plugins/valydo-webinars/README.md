# Valydo · Webinars

Plugin de Escuela Valydo para crear tu funnel de webinar en Systeme.io a partir de la plantilla «PLANTILLA WEBINARS - VALYDO - IA».

## Qué hace

Claude te entrevista sobre tu clase, tu avatar y tu promesa, escribe los textos de las 3 páginas del funnel (registro, gracias y replay), aplica tus colores de marca y te guía en lo que tienes que hacer a mano en Systeme.

## Cómo se instala

En Claude: **Personalizar → Plugins → Añadir → Añadir marketplace** → `consultoria-valydo/claude-plugins`. Después, en **Descubrir**, añade «Valydo · Webinars».

En Claude Code:

```
/plugin install valydo-webinars --marketplace consultoria-valydo/claude-plugins
```

## Cómo se usa

1. Conecta Systeme con Claude (Personalizar → Conectores → conector personalizado con tu clave MCP de Systeme).
2. En un chat nuevo, escribe: «Quiero crear mi funnel de webinar».

## Datos

El plugin no guarda nada. Claude lee y edita tu plantilla en Systeme a través de tu propio conector y siempre te pide permiso antes de cambiar algo.
