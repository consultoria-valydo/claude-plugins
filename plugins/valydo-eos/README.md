# Valydo · EOS

Eos es el Mentor Digital de Escuela Valydo: te acompaña con el método Valydo para vender tu conocimiento online.

## Requisitos

Necesitas un **código de acceso de Valydo**. Si no lo tienes, pídelo al equipo de Valydo.

## Cómo conectarlo

1. Instala el plugin **Valydo · EOS** desde el catálogo de Valydo:
   `/plugin install valydo-eos --marketplace consultoria-valydo/claude-plugins`
2. Ve a **Personalizar → Plugins → Valydo · Eos → pestaña Conectores** y pulsa **Conectar**.
3. Entra con tu email y tu código de acceso de Valydo.

Una vez conectado, pide ayuda a Eos con tu negocio de conocimiento y te guiará con el método Valydo.
