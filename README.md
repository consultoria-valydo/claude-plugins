# Plugins de Escuela Valydo para Claude

Catálogo de skills de Escuela Valydo para alumnos y clientes. Se añade una vez a tu cuenta de Claude y recibes las actualizaciones automáticamente.

## Cómo añadirlo (una sola vez)

1. En Claude, entra en **Personalizar → Plugins**.
2. Pulsa **Añadir → Añadir marketplace** y escribe: `consultoria-valydo/claude-plugins`
3. Activa **Sincronizar automáticamente** para recibir las mejoras sin hacer nada.
4. En **Descubrir**, elige el plugin que necesites y pulsa **Añadir**.

Requiere un plan de pago de Claude (Pro o superior).

## Plugins

| Plugin | Para qué sirve |
| --- | --- |
| valydo-webinars | Crear tu funnel de webinar en Systeme.io a partir de la plantilla de Valydo |
